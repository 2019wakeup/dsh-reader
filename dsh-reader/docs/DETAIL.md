# 阅读（Reader）

在主区域新增一个「阅读」视图：读工作区里的 PDF、EPUB、Word（.docx）、Markdown 与纯文本，划词高亮、写笔记，让模型解释不懂的概念，并在之后悬停概念时原地浮出卡片。

## 用法

1. 打开任意会话，在会话顶部切换到「阅读」。
2. 在书库里点开一个 `.pdf` / `.epub` / `.md` / `.txt` 文件。
3. 选中一段文字：浮出工具条，可「解释」「笔记」「高亮」「复制」；点空白、滚动或 × 关闭。
4. 点击任意高亮可改色、写备注、删除；删除后可点 toast「撤销」，或用 ⌘Z / ⌘⇧Z 撤销重做。
5. 解释生成后会收进概念库；正文里同一概念出现时会有虚线下划线，鼠标停留即可看到卡片。
6. 在概念卡里再选中一个词，可以「再解释」，形成嵌套概念（最多 3 层）。
7. 右侧抽屉提供目录、标注、概念、导读、对话、设置六个面板。
8. 导读：生成章节摘要、全书主旨与核心问题；导图按「书→篇→节」展示，章内分块节点用「（N）+ 要点首句」区分（不再重复章节名），根节点显示去掉扩展名与下载站后缀的书名；导图画布铺一层随平移/缩放同步的点阵网格，暗示可拖拽缩放；可折叠/缩放/跳转，并可导出 SVG/PNG/Markdown；长书显示进度、可停止。
9. ⌘F 搜索全文；Word 跨章搜索；PDF 可切换双页，翻页键可用方向键或 J/K；目录优先显示 PDF 真实书签。
10. 导读按「段 → 篇 → 全书」分层归约，长书有阶段进度、可停止；概念抽屉按当前书过滤；浮窗始终留在阅读区内。
11. 工具栏「译」：Markdown/EPUB/Word 段落双语对照（Word 表格单元格除外）；PDF 右侧译文抽屉按页对照；划词工具条可即时翻译；设置里选目标语言。
12. 读书对话：选中正文点「问 AI」，引用进入底部原生输入框（首行带书名/章节/位置），回车即由当前会话的原生智能体回答；回答实时显示在抽屉「对话」页签，可继续追问，也可「在对话页打开」切到完整对话页。对话按角色分列：提问在右侧品牌色气泡，回答在左侧纸感气泡。回答生成中直接流式显示正文，尚无正文时显示当前动作（正在读取文件/执行命令…），过程折叠与光标保留；引用的原文显示为来源条，过程/工具调用折叠成每条回答里的「过程 · N」，历史轮次与「在对话页打开」收在抽屉标题行，不额外占用对话空间；对话面板与阅读区使用不同底色。消息里的图片通过客户端 Session 服务就地解析显示（点开可看原图），PDF/文档等附件显示为带类型与大小的文件卡；解析失败时降级为文件名占位。选中正文点「问 AI」时，选区内的图片会作为附件加入输入框、内联 SVG 序列化为附件文件、MathML 公式的 TeX 源码写入引用；PNG/JPEG/WebP/GIF 走原生图片附件，其他格式作为文件附件（PDF 文本层没有图片/公式对象，只引用文本）。抽屉「对话」页签可拖拽宽度（默认 420px，320–720），关闭面板时新回答会点亮未读点。面板按角色区分「你」与「助手」，引用消息的书名/位置单独成行；推理与工具调用默认折叠成「过程 · N」，需要看轨迹时点开这条回答里的「过程」展开。
10. 概念可合并、可追问、可记录本书用法；数据可导出 JSON 或 Markdown，导入前有数量确认，设置里可恢复备份。

概念与标注保存在工作区的 `.dsh-reader/store.json`，随工作区走，不上传。

对话面板本身不存消息：它只读当前会话的对话快照，消息由 DSH 会话日志保存。阅读位置与当前窗口文本由客户端上报到 `POST /api/context`，位置进 `store.json` 的 `reading` 字段，窗口进 `.dsh-reader/context.json`（单会话 24000 字，最多 10 个会话），供宿主工具 `reader_context`、`reader_read` 读取；宿主不解析 PDF/EPUB/Word 源文件，Word 的窗口取当前章。

- 数据为 v2：文档以内容指纹为主键，改名/移动后自动重绑；旧版 v1 数据会在首次读取时自动迁移，迁移前备份。
- 每次写入前保留最近 5 份快照（`.dsh-reader/backups/`）。
- 概念卡可编辑、可记录出现位置；父子卡层叠显示；设置（字号/行距/悬停延迟/触发方式）重启保留。

## 动效（0.14.0）

0.14.0 给浮层与跳转补了一层轻量动效：入场与过渡 90–240ms，只动 `transform` / `opacity`（抽屉打开时的宽度与导图连线是明确列出的例外）；退场一律立即卸载，不为了“完整”而延迟关闭。

| 动作 | 表现 |
| --- | --- |
| M-01 划词工具条 | 140ms 从选区一侧浮出，原点贴着选区；第一帧就可点击，最终位置与 0.13.1 一致 |
| M-02 概念卡 | 180ms 贴词浮出（8px 位移 + 0.96 缩放），原点取自词与卡片矩形并夹在 15%–85% |
| M-03 父子卡层叠 | 父卡 180ms 让位 12px 并轻微变暗，子卡独立入场；拖拽期间禁用层叠过渡，命中区域不变 |
| M-04 右侧抽屉 | 打开 180ms 从右边缘展开，内容延迟 40ms 淡入；页签切换只重放内容动画，不重置滚动位置 |
| M-05 读书对话 | 新行 90ms 淡入，流式点 1.2s 呼吸；流式 token 更新不重放入场，自动贴底不变 |
| M-06 导读导图 | 节点按 6ms 错峰缩放淡入（延迟上限 140ms），连线 240ms 画出（延迟上限 80ms），总时长 ≤320ms；最终坐标不变 |
| M-07 跳转定位 | 目录、导图、搜索、概念位置跳转后，目标矩形上浮出一次性定位环：700ms 淡出、不拦截点击、连续跳转只保留最新一个 |
| M-08 按压反馈 | 按钮与列表项按下 90ms 缩到 0.98，松开还原；不作用于拖柄、滚动条与输入框，不改变布局 |

- **Token 作用域**：时长、缓动与缩放入场曲线定义为 `.rd-root` 上的 CSS 变量（单项位移与原点用局部变量/内联变量覆盖），不写 `:root`，不影响 DSH 宿主与其他插件。
- **减少动效**：`prefers-reduced-motion: reduce` 下动画与过渡全部归零，定位环改走静态描边分支（600ms 后移除，不依赖 `animationend`）。需要应急关闭时不发版：给阅读器根节点加 `.rd-motion-off`（该 class 在 React 重渲染后仍保留），或导入一份含 `prefs.motion: "off"` 的 store JSON（`prefs.motion` 支持 `system`/`full`/`off`）。
- **性能降级**：PDF 或大于 200KB 的文档，抽屉打开不做宽度动画，只保留内容淡入；导图连线超过 60 条时改为整图分组淡入，不逐条绘制；折叠/展开新增节点只做 90ms 淡入，不重放全图。
- **全屏导图**：全屏时导图渲染在阅读器根节点而不是抽屉里——抽屉内容入场动画会留下一个 `transform`，它会让抽屉内所有 `position:fixed` 后代以抽屉为包含块；离开全屏后导图回到抽屉并保留平移/缩放状态。
- **测试门禁**：`node eval/motion.mjs` 用 `document.getAnimations()` 校验真实动画与降级（≥15 项），并作为 `node scripts/release-check.mjs` 的第 12 项随发布门禁一起跑。

## 当前限制

- 扫描版 PDF 没有文本层，不能标注。
- 固定版式 EPUB（FXL）不支持。
- `.doc` 旧格式、`.rtf`、`.wps` 不支持；Word 不还原分页、页眉页脚、分栏、文本框与页码。
- 加密/密码保护的 Word 文档无法打开。
- Word 的修订显示为“接受所有修订后的最终稿”，批注不显示。
- 段落对照翻译、概念图谱、移动端尚未包含。
- 解释/导读/追问需要 DSH 已配置可用的模型。
- 读书对话的输入框、模型选择与工具能力由 DSH 提供；旧版 DSH 缺少对话标准 props 时，「问 AI」入口与「对话」页签自动隐藏，其余功能不受影响。
- `reader_read` 只读最近一次上报的阅读窗口：PDF 是当前页前后，文本类书是当前滚动位置附近（滚动节流上报），跨章或全书检索需要用户翻页/滚动后再问。
- 解释调用有 90 秒死线（`DSH_READER_EXPLAIN_TIMEOUT_MS` 可调）：模型不返回时请求被中止，卡片显示超时并保留重试入口，失败原因写入 `debug.lastError`。
