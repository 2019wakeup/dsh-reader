# 砚读 1.0 发布说明（候选 0.10.0）

> 状态：**1.0 候选**。功能已冻结，等待两项人工验收：三本真实书 dogfood、浏览器视觉/键盘走查。0.10.0 已处理一轮独立审查的 2 个 Critical、9 个 Important，并补齐标注导出、概念合并、内容变更重绑、搜索、主题、FXL 提示、键盘激活、PDF 命中、导读进度/取消、发送记录、PDF 双页与 J/K 翻页。
> 安装：`plugin_manager` 安装 `dsh-reader/`；升级后刷新页面。数据格式 v2，自动迁移并备份。

## 1. 这是什么

DSH 里的阅读工作台：读 PDF / EPUB / Markdown，划词标注与撤销，让模型解释概念并沉淀成卡片，父子卡层叠复用；读完整本书生成章节摘要、全书主旨与可交互思维导图；数据可导出迁移。

## 2. 功能清单

**阅读**
- PDF（文本层、缩放、翻页）、EPUB（目录、内链、图片）、Markdown/TXT。
- 字号/行距/主题、阅读位置记忆、键盘翻页、`?` 快捷键面板。

**标注**
- 四色高亮、笔记、撤销/重做、点击编辑、删除；跨粗体/代码的高亮逐段包裹；锚点失效可见提示。

**概念**
- 划词解释（定义/直觉/本书语境/例子/依据原文）、词边界匹配、出现位置与跨文档跳转。
- 父子卡层叠（≤3 层）、悬停卡 + 扩大的悬浮区、别名/合并基础、概念编辑（模型不再覆盖用户版本）。
- 追问 Q&A（带相关概念上下文）、本书用法补充（同概念跨书追加，不覆盖）。

**导读**
- 章节摘要（3 句 + 要点）、全书主旨、3 个核心问题、增量缓存（只重算改动章节）。
- 树状思维导图：折叠、缩放、点击跳转；导出 SVG / PNG / Markdown。

**数据与系统**
- Store v2：内容指纹主键（改名/移动不丢）、v1 自动迁移、写前备份（保留 5 份）。
- 导出/导入 JSON、概念/标注/导读随库迁移；错误边界可复制诊断信息；中英双语。

## 1.9 翻译（0.7.0，P1.1）

- Markdown/EPUB 阅读区工具栏「译」开关：开启后**每个段落/标题下方**插入译文（左侧细线、弱化色），不影响划词、标注、概念卡；关闭即恢复。
- 设置里选目标语言（简体中文 / English / 日本語）；按章按需翻译、背景缓存。
- Host 侧按段落内容哈希缓存到 `docs[docKey].translations[lang]`，同段不重复计费；一次请求按 8 段/3500 字符分批，20 段以内通常 1–3 次模型调用。

## 2.0 长书导读系统（0.6.0）

> 0.6.1 补充：工具栏加入撤回/重做按钮（带可用状态），搜索/设置等图标换成 18px SVG，视觉门禁新增图标尺寸断言。
> 0.6.3 补充：用两本真实书（（一本真实中文书）PDF 84MB/523 页、EPUB 70MB/27 章）做 dogfood。发现 PDF 书签损坏（26 条书签大多指向同一页），新增「书签可信度校验 + 按排版识别章节」兜底，恢复到 23 个章节、覆盖 3–521 页；EPUB 结构正常。真书导读抽样（3 段 + 2 篇）12.4s 完成，摘要与主旨质量正常；真书划词「康波」快速解释 2.46s、深入 2.13s。同时修复导读在最高推理强度下 400 token 被推理耗尽导致的 `empty guide section`：导读改用低/中推理强度 + 900 token 预算 + 纯文本兜底。
> 0.6.2 补充：解释按路由分层——默认「快速解释」（短 JSON + 低推理强度），卡片标「快速」并提供「深入解释」按需升级；已存在概念直接命中缓存不调模型。实测：快速 2.39s、深入 4.70s、缓存 0.00s。

真实书动辄数百页、几十万字，旧的「每 10 页切一段」既不跟目录也不覆盖全书。0.6.0 重构为结构感知的分层流水线：

- **结构解析**：PDF 优先读取内嵌书签（`getOutline`，解析命名/引用目标到页码），EPUB 用章节，Markdown 用标题；解析结果同时用于目录树。
- **章级分层**：目录条目 → `parts`（篇/章），每章按页预算切成 `sections`（每段 6000 字符，超长取头尾样本），总段数 ≤72、篇数 ≤24，覆盖到全书末页。
- **两段式归约**：先逐段摘要，再按篇归约（`buildPartPrompt`），最后用篇摘要生成全书主旨与核心问题；篇摘要带缓存哈希，内容不变时二次生成 0 次模型调用。
- **导图分层**：思维导图变为「书 → 篇 → 节」三层；Markdown 导出现在按篇分组。
- **进度可见**：分析目录 → 逐段 → 逐篇 → 汇总，四阶段进度与停止；批量前显示段/篇/token 估算。
- **目录树**：PDF 显示真实书签（缩进、页码、当前页高亮）；无书签时用 20 页一组的分组列表，避免几百项长列表。
- **概念按书过滤**：概念抽屉默认「当前书」，可切「全部」；未关联当前书时自动回退全部。
- **浮窗边界**：卡片/编辑卡/迷你菜单按阅读区（不是窗口）边界定位，优先侧边、次选上下，窄屏不越界。

实测（Ghostscript 生成带书签 PDF）：5 条书签全部解析出正确页码，5 篇/5 段，覆盖 1–5 页；视觉门禁新增长书导图、概念按书过滤、窄屏浮窗边界。

## 2.1 解释路由（0.6.2）

- 新词默认走 **quick** 路由：只要求定义/直觉/例子，`maxTokens=260`，按模型支持的最低推理强度（`minimal→low→medium→high→max` 里第一个可用项）调用；
- 卡片显示「快速」标记与「深入解释」按钮；点击后走 full 路由补齐语境/例子并合并，不覆盖用户编辑；
- 命中已有概念时直接返回（`route=cached`），跨书「本书用法」也只在 full 深度下触发，避免每次悬停解释都多一次模型调用；
- 同词并发 still single-flight，quick/full 分开去重。
