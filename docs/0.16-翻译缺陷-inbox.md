# 0.16 翻译缺陷 inbox

## 流程

1. **inbox**：用户反馈/线上问题先记一条，不直接改代码。
2. **triage**：判断影响面（语言/格式/结构/缓存/性能）、P0/P1、是否需要 live case。
3. **失败用例**：先在 `test/` 或 `eval/translate/` 补一条会失败的用例。
4. **修复**：最小改动；涉及 prompt/术语/模型时按 #19 变更协议 bump 版本、跑 tune+holdout、附报告。
5. **promote**：回归通过的用例进入固定语料/视觉组，关闭 inbox 条目。

### BUG-YYYYMMDD-NN
