## 章节上下文快照

输入：`chapterTitle`、`summary`、`keyPoints`、`concepts`（本 doc 出现过的术语）、书名。  
输出：`{ title, chapter, chapterSnapshot }`，由 #14 作为 `context.chapterSnapshot` 注入 prompt v2。  
无导读/概念时回退书名 + 章节标题；不额外请求模型。  
缓存 key 包含 `docKey/chapter/摘要/前后文`，relink 或内容变化不会误用旧快照。

## 批次 checkpoint 契约（交 #16）

- 单位：已有 `TranslationUnit`（id/hash/contentHash/text）。
- 批次成功后才把该批译文写入 store；`failed[]` 永不写入。
- 同一批重试按 contentHash/版本化 cache key 命中，不重复计费。
- 不建独立 progress 文件；用现有 store translations + checkpoint 状态。
- PDF/长文切页/切章时保留已完成批次；未完成批次可继续。
