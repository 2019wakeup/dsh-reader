# 砚读 0.16.0 — 翻译质量闭环

0.16.0 把翻译从“能翻”推进到“可重试、可解释、可验证”：9 种目标语言、术语表、版本化缓存、表格、PDF 分页预取、分层 eval 与发布门禁。

## 新功能

- **9 语言 + auto**：简中/英/日/韩/法/德/西/俄/葡；源语言自动检测，同语言不请求，可强制。
- **术语表 v1**：设置里维护全局术语；最长匹配注入 prompt；术语变化使旧缓存失效并刷新可见区域。
- **章节上下文**：复用导读摘要 + 概念库生成章节快照，不额外调用模型；划词带所在句。
- **版本化缓存**：target/from/promptVersion/glossaryHash/contentHash；旧纯文本译文显示但标“旧译文，待刷新”；每语言 2000/每文档 8000 条 LRU。
- **表格**：仅译文模式按单元格翻译，保留 table/colspan；对照模式保持原文。
- **PDF**：当前页优先、空闲预取下一页；无文本层明确提示；页切换不吞请求。
- **失败恢复**：缺 id/坏 JSON/超时/429 分类文案；失败块保留；单块/批量重试。
- **eval 与门禁**：60 段语料 + 40 条 L1 合同；`eval/translate.mjs --offline`；live 判官与 14 项 release-check。

- live 判官与生成器同为 `deepseek-flash`，已标 same-source；120 段人工校准按产品风险豁免不阻塞 0.16.0，但不是独立质量证明。

- 未做浏览器 10k 字 long-task 基准；批大小、缓存、LRU 已实现。

## 升级注意

- 0.16 起写入 9 语言译文；降级回只认简中/英/日的旧版本前，请先用「导出」保存。
- 缓存键已版本化，旧译文会显示但标 stale；如需要新 prompt/术语，重新翻译即可。
- 全新 0.16.0 包需要重启 DSH 生效。
